# HubGrade

Un dock façon Mac pour Windows 10 et 11 : tes applis, des widgets, une recherche et des notifications au même endroit, dans un style propre.

## Installation

1. Télécharge **HubGrade.exe** dans la dernière version : [Releases](../../releases/latest).
2. Mets le fichier dans un dossier à toi que tu gardes (évite le dossier Téléchargements).
3. Double-clique dessus.

C'est tout. Pas d'installateur, rien à extraire, aucune dépendance : l'exécutable fait le reste et se met à jour tout seul.

## Clé

HubGrade demande une clé pour s'activer. Ton PC est reconnu même après une réinstallation. Pour obtenir une clé, contacte le créateur : son Discord est affiché directement dans l'écran d'activation de l'appli.
